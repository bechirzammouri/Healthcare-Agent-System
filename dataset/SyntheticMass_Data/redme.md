# SyntheticMass Data Directory

This directory is empty. It previously contained the original SyntheticMass dataset files, which were large and have been deleted.

## Original Data Files (Removed)

The following CSV files were originally located here:
- `patients.csv`
- `encounters.csv`
- `conditions.csv`
- `medications.csv`
- `procedures.csv`
- `immunizations.csv`
- `observations.csv`
- `careplans.csv`
- `allergies.csv`

## Current Data Location

Sampled versions of these files are available in the parent directory:
- `../sampled_patients.csv`
- `../sampled_encounters.csv`
- `../sampled_conditions.csv`
- `../sampled_medications.csv`
- `../sampled_procedures.csv`
- `../sampled_immunizations.csv`
- `../sampled_observations.csv`
- `../sampled_careplans.csv`

These sampled files contain a subset of the original data for development.
